kiwi-ng

kiwi-ng builds operating system images from an image description: a directory with a config.xml or *.kiwi file and optional files such as scripts or an overlay tree. The commands are grouped into the services system (build images), result (work with build results) and image (work with image descriptions and images). Plugins can add commands to the system service.

Usage

kiwi-ng [global options] <service> <command> [options]
kiwi-ng <service> <command> --help | help
kiwi-ng --help | --version | --install-completion | --show-completion

The global options must be given before the service. --help shows the usage of a service or command, help after a command opens its manual page.

Global Options

Options marked with ... can be given multiple times.

Option

Description

--type <build_type>

The image type to build, instead of the default type of the image description. The former type vmx is replaced by oem.

--profile <name>...

Select a profile of the image description. Without it, the profiles with import="true" are used. See Profiles.

--kiwi-file <file>

The image description file in the description directory. Default: config.xml, image/config.xml, then the first *.kiwi file in alphabetical order.

--target-arch <name>

The image architecture, by default the one of the build host. A different architecture requires the host to be set up to run its binaries first, which is not part of KIWI NG.

--config <file>

An additional runtime configuration file with the highest precedence. It must exist. See The Runtime Configuration File.

--shared-cache-dir <directory>

The shared cache of repository metadata and packages, bind mounted into the image root during the build. Default: /var/cache/kiwi.

--temp-dir <directory>

The base directory for temporary files. Default: /var/tmp.

--setenv <variable=value>...

Set an environment variable for KIWI NG and the tools and scripts it calls.

--debug

Print debug messages, same as --loglevel 10.

--loglevel <number>

Only print messages at or above the level: 10 debug, 20 info, 30 warning, 40 error, 50 critical.

--logfile <file>

Write all messages, including debug messages, to the file. With --logfile stdout, write them to standard output instead.

--logsocket <socket>

Send all messages to the Unix domain socket, in the format of --logfile.

--color-output

Print errors, warnings and debug messages in color.

--debug-run-scripts-in-screen

Run the scripts of the image description in a screen session, see Scripts.

--version

Print the version of KIWI NG.

--install-completion

Install the shell completion for the current shell.

--show-completion

Print the shell completion for the current shell.

Example

$ git clone https://github.com/OSInside/kiwi
$ sudo kiwi-ng --type oem system build \
    --description kiwi/build-tests/x86/leap/test-image-disk \
    --set-repo https://download.opensuse.org/distribution/leap/16.0/repo/oss \
    --target-dir /tmp/myimage
